AI when you choose.

Clearframe works without an account or API key. Optional AI can improve summaries and translate them.

Optional AI

Off by default. Page text is sent only when you click an AI or translation button.

Prototype security note

Your key stays in this browser profile’s local extension storage and requests go directly to OpenAI. A production release should use a backend proxy and user authentication—never ship a shared key.

What Clearframe does not do

  • It does not collect or sell your browsing history.
  • It does not run on every page in the background.
  • It does not insert ads or paid recommendations.
  • It does not claim that risk signals prove a page is safe or unsafe.
